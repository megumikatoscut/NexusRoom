# Changelog / 更新日志

## [v1.0.0](https://github.com/megumikatoscut/NexusRoom/releases/tag/v1.0.0)

Initial GitHub release for Windows x64 and Android. Both applications use version 1.0.0; Android versionCode is 15.

首次 GitHub 发布，支持 Windows x64 与 Android。双端应用版本均为 1.0.0，Android versionCode 为 15。

- LAN rooms, discovery, invitations, pinned TLS and permissions. / 局域网房间、发现、邀请、证书绑定 TLS 与权限。
- Bidirectional remote control, file exchange and clipboard sharing. / 双向远程控制、文件交换与剪贴板共享。
- WebRTC calls and meetings. / WebRTC 通话与会议。
- PC Harness Agent, Android-local Agent, request and automatic modes. / PC Harness Agent、Android 本地 Agent，以及请求和自动模式。
- Local bilingual voice recognition and optional wake-to-Agent. / 本地中英语音识别与可选唤醒 Agent。
- Independent source repository with bilingual docs, dependency locks, CI and release checksums. / 独立源码仓库，提供双语文档、依赖锁定、CI 与发布校验值。

The release preserves the supplied EXE/APK bytes. Repository and documentation changes do not rebuild these binaries. See [release details](docs/releases/v1.0.0/README.md).

本次发布保留原有 EXE/APK 字节内容。仓库和文档调整不重建安装包，详见 [发布记录](docs/releases/v1.0.0/README.md)。
